# Askey
É um codificador e decodificador ASCII, feito inteiramente em bash.

## !!!AVISO!!!
**Isso definitivamente não é criptografia!!!**

## O que o Askey faz?
Ele apenas codifica ou decodifica frases ou palavras em ASCII, no caso, ele pode codificar simples frases em código ASCII.

## Como instalar

```bash
git clone https://github.com/Ex3cutor76-V1/Askey.git
cd Askey/
./install.sh
```

## Dependências
```bash
od
```

## Comandos

* Sintaxe base
```bash
askey <flag> argumento
```
| Flag | Descrição |
|------|-----------|
| -e ou --encode | Codificar texto |
| -d ou --decode | Decodificar texto |
| -ve ou --verbose-encode | Codificar em modo verboso |
| -vd ou --verbose-decode | Decodificar em modo verboso |
| -h ou --help | Exibir ajuda |
| -v ou --version | Exibir versão |
